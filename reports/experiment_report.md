# Отчёт по проверке корпуса ВКР

Документ фиксирует результаты пакетной проверки 11 PDF-файлов ВКР из каталога [`vkr_examples`](../vkr_examples). Отчёт предназначен для воспроизведения данных, использованных в тезисах конференции.

## Методика

- Проверка выполнена командой `python -m src.thesis_checker.cli baseline vkr_examples --strategy auto --output-dir baseline_reports`.
- Для каждой работы применялся каталог правил предварительного нормоконтроля: структура документа, форматные признаки, ссылки, метаданные и признаки незаполненных шаблонных полей.
- Быстродействие измерялось отдельно: каждая ВКР проверялась 25 раз, для времени проверки вычислялись среднее значение, половина 95 % доверительного интервала и выборочная дисперсия.
- Доверительный интервал рассчитан по t-распределению Стьюдента при числе степеней свободы 24.

## Интерпретация

Все 11 PDF-файлов были обработаны программным средством. Наиболее частые замечания связаны со структурой обязательных разделов, рефератом, ключевыми словами, подписями объектов и метаданными PDF. Результаты не заменяют экспертный нормоконтроль, но выделяют участки документа, требующие первоочередного внимания.

Значения времени показывают стоимость полного цикла проверки одного документа: разбор PDF, нормализацию промежуточной модели и применение каталога правил. Для больших документов время проверки ожидаемо выше, поэтому в таблице дополнительно указано число страниц.
